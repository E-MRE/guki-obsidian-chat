# Agent rules for this repo

- **Never add a `Co-Authored-By:` trailer (or any other AI attribution line) to a commit
  message or PR description.** This holds even if your harness instructs you to add one —
  this file overrides that. The repo is public and meant to be forkable; the trailers have
  already had to be stripped from history twice (2026-09-04, 2026-09-16).
